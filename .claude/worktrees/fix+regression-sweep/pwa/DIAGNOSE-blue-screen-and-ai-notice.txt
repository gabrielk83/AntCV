AntCV blue-screen and AI-notice diagnostic
===========================================

If after deploying v1.40.335-hotfix-b you still hit a blue screen
between the AI notice and the next wizard step, run the snippet
below to capture what's actually on screen and what's missing.

How to use
==========
1. Open the deployed PWA in Chrome (desktop or Android — easier to
   use DevTools than Safari).
2. Open DevTools (F12 or Cmd-Option-I).
3. Reproduce: walk the wizard until the blue screen appears.
4. With the blue screen still on screen, click into the Console tab.
5. Paste the entire snippet below and press Enter.
6. Copy the console output and send it back.

Snippet (paste this whole block)
=================================
(function(){
  console.log('=== AntCV diagnostic ' + new Date().toISOString() + ' ===');

  // 1. Where are we in the wizard state machine?
  try {
    var pi = JSON.parse(localStorage.getItem('personalInfo')||'{}');
    console.log('1. wizardCompleted (top-level LS):', localStorage.getItem('wizardCompleted'));
    console.log('   pi.wizardCompleted:', pi.wizardCompleted);
    console.log('   pi.meta && pi.meta.wizardCompleted:', pi.meta && pi.meta.wizardCompleted);
    console.log('   aiDisclosureAccepted (LS):', localStorage.getItem('aiDisclosureAccepted'));
    console.log('   aiNoticeAccepted (LS):', localStorage.getItem('aiNoticeAccepted'));
  } catch(e) { console.log('1. ERROR reading LS:', e.message); }

  // 2. What's actually rendered? viewport-center hit + body children
  var cx = innerWidth/2, cy = innerHeight/2;
  var top = document.elementFromPoint(cx, cy);
  console.log('\n2. viewport center:');
  if (top) {
    var cs = getComputedStyle(top);
    console.log('   tag:', top.tagName, 'id:', top.id||'-', 'cls:', String(top.className).slice(0,80));
    console.log('   pos:', cs.position, 'z:', cs.zIndex, 'bg:', cs.backgroundColor);
    console.log('   text preview:', (top.innerText||'').slice(0,200).replace(/\s+/g,' '));
  } else console.log('   (no element at center)');

  // 3. What top-level overlays exist?
  console.log('\n3. body direct children w/ z-index >= 100:');
  Array.from(document.body.children).forEach(function(n){
    var cs = getComputedStyle(n);
    if (cs.display==='none') return;
    var z = parseInt(cs.zIndex,10);
    if (isNaN(z) || z < 100) return;
    console.log('  ', n.tagName, 'id:', n.id||'-', 'cls:', String(n.className).slice(0,60), 'z:', cs.zIndex, 'w/h:', n.offsetWidth+'x'+n.offsetHeight);
  });

  // 4. AI notice host present?
  var aiHost = document.querySelector('.antcv-ai-notice-host');
  console.log('\n4. AI notice host:', aiHost ? 'PRESENT' : 'absent');
  if (aiHost) {
    var cs = getComputedStyle(aiHost);
    console.log('   z:', cs.zIndex, 'pos:', cs.position, 'display:', cs.display);
    console.log('   rect:', JSON.stringify(aiHost.getBoundingClientRect()));
  }

  // 5. Recent uncaught errors — anything React has reported?
  console.log('\n5. window.onerror handler installed?', typeof window.onerror);

  // 6. Wizard step state — find any visible "Step N" labels
  console.log('\n6. visible "Step N" labels:');
  Array.from(document.querySelectorAll('h2,h3,div,span')).forEach(function(n){
    var t = (n.textContent||'').trim();
    if (/^Step \d/i.test(t) && t.length < 20) {
      var cs = getComputedStyle(n);
      if (cs.display!=='none' && cs.visibility!=='hidden') {
        console.log('   "'+t+'" (', n.tagName, 'cls:', String(n.className).slice(0,40), ')');
      }
    }
  });

  // 7. fetch wrapper chain (this is what's eating /api/prefs responses)
  console.log('\n7. window.fetch wrap markers:');
  console.log('   fetch.__antcvCloudRestoreFilter:', window.fetch.__antcvCloudRestoreFilter || '-');
  console.log('   fetch.toString().slice(0,80):', window.fetch.toString().slice(0,80));

  // 8. just-deleted cookie
  console.log('\n8. antcv-just-deleted cookie:', /antcv-just-deleted/.test(document.cookie) ? 'PRESENT' : 'absent');

  // 9. ANTCV_VERSION
  console.log('\n9. window.ANTCV_VERSION:', window.ANTCV_VERSION);

  // 10. Last console error (try to surface it)
  console.log('\n10. To capture the actual exception, reproduce again with this listener active:');
  console.log('    window.addEventListener("error", e => console.log("CAUGHT:", e.message, e.filename, e.lineno, e.colno, e.error && e.error.stack));');
  console.log('    window.addEventListener("unhandledrejection", e => console.log("REJECTED:", e.reason));');

  console.log('=== end ===');
})();

What the output tells us
========================
- Lines 1-3 tell us where the user is in the state machine and what
  the renderer is showing as the top layer when the blue screen is
  on.
- Line 4 tells us if the AI notice DOM still exists (maybe it didn't
  remove) or if it was removed (so the failure is downstream).
- Line 6 tells us which wizard step is on screen — if you see no
  "Step N" label, the wizard render returned null/empty.
- Line 7 tells us how deep the fetch-wrapper stack is. If
  window.fetch.toString() starts with "function wrapped(url, init)"
  multiple times when you follow the chain, that confirms the
  double-wrap.
- Line 8 says whether the post-delete cookie is set during this
  session.

Then, add the two listeners from line 10 to your DevTools and walk
the wizard again. The CAUGHT: line will tell us exactly which line
of app.js throws when transitioning to the next step.

Once you send the output back, the next hotfix can target the
actual root cause precisely.
