## End-to-end flow (post-v1.50.x)

```
User picks style + chips in WritingStylePicker
        │
        ▼
personalInfo.writingPrefs = { style, chips, extraBannedWords[lang], ... }
personalInfo.exportPrefs   = { ats, legacyAtsTier }
personalInfo.stylePackage  = "copenhagen-modern"   (PackagePicker)
        │
        ▼
PWA fetch wrap (src/lib/install-fetch-wrap.ts) intercepts LLM-shaped POSTs
        │
        │   body._antcv_writing_style = { ...writingPrefs, ...layoutPrefs, ats, package }
        ▼
Proxy worker (cv-proxy) reads _antcv_writing_style:
        │
        │   1. parseWritingStyleRequest  → canonicalise style id, clamp targetPages
        │   2. buildStyleSystemPreamble  → prepend to provider system content
        │   3. delete _antcv_writing_style before forwarding to provider
        │   4. log selection event to ANALYTICS KV
        │   5. force stream:false on Anthropic (for buffering)
        │
        ▼
Provider (Anthropic / OpenAI / Mistral / Gemini) returns draft
        │
        ▼
Proxy worker executeSceWithRetry:
        │
        │   1. evaluateSce on extracted text (case-insensitive word match;
        │      case-insensitive + punctuation-tolerant phrase match)
        │   2. if dirty AND attempts < 3: reCallProvider(fixInstruction)
        │   3. after retry loop: applyAtsGlyphConversion when ats:true
        │   4. log sce-eval event with attempts + flagged
        │   5. attach X-AntCV-Sce-* + X-AntCV-Ats-Applied headers
        │
        ▼
PWA observability tap (v1.50.5) reads headers
        │
        │   recordEntry() → circular buffer + CustomEvent dispatch
        ▼
Breadcrumbs island (v1.50.9) subscribes, renders bottom-right panel
        │
DOCX export hits docx-worker:
        │
        │   payload.package + payload.legacy_ats_tier → palette.js
        │     getPackageStyle(...) → DEFAULTS-shaped style block
        │     mergeStyle(payload.style, ...) — overrides win
        │   render OOXML with style.* throughout
        ▼
Word/PDF exported with the same palette the PWA preview shows
```
