# v1.50.11 — Pass 4 step 1: activate 5 deferred commercial styles

**Plan citation:** AntCV_Plan_v2_LockedSources.md §7 Pass 4 — "Activate Structured Professional, Credential Forward, Precision Formal, Prestige Structured, Mediterranean Formal."
**Branch:** `feat/v1.50.11-pass4-activate-styles`.
**Build version:** `1.50.11`.

## What this PR does

Flips `active: true` on the 5 commercial styles that were defined in `writingSystems/registry.json` since v1.50.0 Pass 3 but flagged "Coming v1.51". The picker UI (`src/islands/WritingStylePicker/`) filters its dropdown by the `active` field, so users can now select any of these 5 styles immediately. The worker side (`workers/proxy/src/writing-style-engine.js`) has had them in its STYLES map since v1.50.0 Pass 3 — the routing logic doesn't consult `active`, so this is a UI-gating change only.

Activating:
- **Structured Professional** — process-led framing; methodology + scope first
- **Mediterranean Formal** — relational warmth within formality; longer sentences
- **Prestige Structured** — institutional weight; scope-heavy verbs (revenue, headcount, P&L)
- **Credential Forward** — credentials surfaced early; named certifications inline
- **Precision Formal** — numerical precision; exact percentages, units, ranges

After this PR: **10 of 12 styles active** at the v1.50.11 cut.

Still deferred:
- **Research Formal** — v1.52 (Pass 5 academic layout + new sections)
- **Hybrid Balanced** — depends on the remaining Pass 4 work (chip-conflict auto-swap UI). Currently the picker DETECTS chip conflicts and shows a `⚠` icon + warning banner, but doesn't auto-shift the style to Custom Tone. Hybrid Balanced needs that resolution path to behave correctly per plan §4.6.

## Verification

After deploy:

1. Settings → Personal → Writing style — dropdown now shows the 5 newly activated styles as **selectable** (no `(Coming v1.51)` suffix).
2. Selecting any of them re-seeds default chips per the cascade (e.g. Precision Formal → `precise, quantified, technical`).
3. Trigger an AI generation — proxy worker logs the `writingStyle: <new style>` selection event. The §4.7 system preamble carries the style's `primaryConstraint`, `contentRule`, `avoidRule` to the LLM.
4. The Breadcrumbs panel (v1.50.9) shows the new style in its latest entry.

```js
// In DevTools console after a generation:
window.AntcvObservability.readBuffer().slice(-1)[0]
// → { writingStyle: 'precision-formal', targetLanguage: 'en', ... }
```

## Risk

- **No worker redeploy needed.** The proxy worker's STYLES map already includes all 12 styles since v1.50.0 Pass 3. The `active` flag in the worker is for documentation/hygiene only.
- **Defaults don't change for existing users.** Anyone whose `personalInfo.writingPrefs.style` is already set keeps their existing style. New users still default to `nordic-minimal` (the locked-source default).
- **Output quality.** The 5 newly activated styles have full `primaryConstraint` / `constraintAvoid` / `constraintPrefer` / `contentRule` / `avoidRule` data in the registry. The proxy worker's preamble path uses these directly. v1.50.3's SCE retry loop still applies — banned-list filtering works identically.
