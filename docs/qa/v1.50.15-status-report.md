# v1.50.15 — Pass 5 step 1: activate research-formal + academic sections

**Plan citation:** AntCV_Plan_v2_LockedSources.md §7 Pass 5 — Research Formal academic register + new sections (Research Experience / Publications main / Grants & Fellowships / Conferences & Talks / Teaching & Supervision / Technical Methods / Industry Experience / Professional Service / Work Style).
**Branch:** `feat/v1.50.15-research-formal-activation`.
**Build version:** `1.50.15`.

## What this PR does

First foothold into Pass 5. Two changes, both bounded:

1. **Activate `research-formal`** — flips `active: true` in `writingSystems/registry.json`, adds to `activeAtCut`, drops the v1.52 "Coming" badge. Worker `STYLES` mirror updated for hygiene. WritingStylePicker now offers Research Formal as a selectable style.

2. **Academic section catalogue in the LayoutPicker** — adds `ACADEMIC_SECTIONS` (11 sections from `cv-skeleton-academic.md` + `research-formal.sectionOrder`). The LayoutPicker panel renders a new collapsible "Academic sections" group below the existing "Commercial sections" list. Group auto-expands when the active style is `research-formal`; collapses otherwise.

After this cut: **12 of 12 styles active**. The full Pass 4 + Pass 5 style roster is live.

Per-section overrides stored under `personalInfo.layoutPrefs.{sectionFormats, lineLimits}` flow through the proxy worker preamble regardless of which style is currently active. The worker's `parseWritingStyleRequest` already accepts arbitrary section ids (the maps are generic), so adding new section keys on the PWA side automatically works on the worker side — no deploy required.

## What this PR does NOT do

Pass 5 has several other deliverables the plan calls out. These remain deferred:

- **Academic DOCX layout** — DOCX worker emits a different OOXML structure for research-formal (publications-prominent, education-near-top, two-column research). Requires modifying `workers/docx-worker/src/generate.js` to switch on the active style. Substantial.
- **Photo positioning beyond Sidebar-top** — current PWA + DOCX worker support `sidebar-top` / `sidebar-bottom` / `header-left` / `header-right` / `main-left` / `main-right` / `hidden`. Research Formal often suppresses the photo entirely; that's already covered. New positions are out of scope here.
- **Dark-mode export** — `packages/registry.json` already carries dark-mode variants per package; the export pipeline doesn't yet consume them. PWA preview gets dark mode "free" once `body[data-dark-mode="active"]` is set, but DOCX/PDF export needs worker work.

These are each their own focused cuts.
